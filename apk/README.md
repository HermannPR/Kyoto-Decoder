# APK de Hivemind Chat (debug)

Compilados de prueba de la app Android de Hivemind Chat. **No son de Kyoto
Decoder**; se guardan aquí solo como punto de descarga.

- `HivemindChat-publica-debug.apk` — sin canal precargado.
- `HivemindChat-equipo-debug.apk` — variante del equipo.

Firmados con la clave de **debug**: en el teléfono activa "instalar apps
desconocidas" para instalarlos. No sirven para Play Store (eso requiere una
keystore de release).
